# Coin-Die-SNA
Social Network Analysis based on die studies of ancient coin collections and their findspots.

## Architecture & Submodule

This application relies on a modular backend to handle data processing and pipeline execution. This logic is encapsulated in the **Coin-Die-SNA-Interface** submodule.

* **Backend / Interface:** [https://github.com/Lukas-Horst/Coin-Die-SNA-Interface](https://github.com/Lukas-Horst/Coin-Die-SNA-Interface)

> **Installation Note:** When cloning this repository, ensure you also initialize the submodule:
> ```bash
> git clone --recurse-submodules <REPO_URL>
> ```

## Configuration

Before starting the server, you must configure the `config.json` located in the interface directory. This file connects the web frontend with your local data and the analysis pipelines.

The following sections in the config are critical for the application to function:

1.  **`paths`**:
    * Define the absolute paths to your image folders (`images_obverse`, `images_reverse`).
    * Link your metadata files (e.g., `findspot_data`, `die_ground_truth`).
    * Set the `output_dir` and `cache_dir`.

2.  **`visualization_settings`**:
    * Determine how the visual matching comparison in the inspector works (e.g., which algorithm ID to use).

3.  **`pipelines`**:
    * You must configure the specific pipeline referenced by your visualization settings (either `auto_die_studies` or `die_study_tool`).
    * Ensure the `install_path` to that pipeline is set correctly, as the frontend uses it to generate on-the-fly visualizations of keypoint matches.

## Usage & Frontend

To view the results and start the application:

1.  Run the `webserver.py` script.
2.  Open your browser at `http://localhost:5001`.

### Workflow
* **Die Data Tab:** Select which die study result files (JSON) you want to use for the obverse and reverse analysis.
* **Start Analysis:** Click the start button to initialize the social network analysis pipeline. This may take a few seconds to process.

### Visualization Features
* **Force Graph & Map View:** Navigate the networks by dragging and zooming. These views visualize the relationships between dies and findspots.
* **Inspector:** Clicking a node reveals detailed SNA metrics and the list of associated coins.
* **Keypoint Visualization:** Select two coins within a cluster to view the calculated visual matches (edges/keypoints) generated by the configured pipeline.
* **Filters:** Use the top bar to toggle between reverse/obverse datasets or filter coins by specific types (e.g., Allen Types).
